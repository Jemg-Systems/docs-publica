# os

`os.jemg.dev` es la cara pública del ecosistema y, a la vez, su panel de mando. Sirve el
portfolio, este blog y esta documentación, y expone un servidor MCP para administrarlo
desde Claude.

Corre Laravel 13 con Vue 3 sobre Inertia, en un solo contenedor con FrankenPHP en modo
clásico, detrás de Traefik y Cloudflare.

## Por dónde empezar

- **[Instalación](/docs/os/instalacion)** — levantarlo en local.
- **[MCP](/docs/os/mcp)** — administrar el hub desde Claude.
